1.
Drop the old database
docker exec -it turniejrejestrator-postgresdb_container psql -U postgres -c "DROP DATABASE turniejrejestratordb;"

2a.
Create role
docker exec -it turniejrejestrator-postgresdb_container psql -U postgres -c "CREATE USER programturniejrejestrator WITH PASSWORD 'lavo24';"
2.
Create a fresh empty database:
docker exec -it turniejrejestrator-postgresdb_container psql -U postgres -c "CREATE DATABASE turniejrejestratordb;"

3.
Copy the dump file into the container
  -utworzenie katalogu (byæ mo¿ê ju¿ jest)
